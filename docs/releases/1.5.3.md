# WeSight for Obsidian 1.5.3

发布日期：2026-11-24。

维护版本：清理不再使用的代码与重复资源，更新文档。功能与界面行为保持不变。

## 代码整理

- 移除设置页中已被新版模型配置界面取代的旧表单（旧版供应商编辑、导入导出入口及其辅助函数）。模型配置的导入、导出继续通过现有「导入」「复制配置」入口使用。
- 移除聊天视图、公众号预览、飞书分享面板和飞书 CLI 服务中未被调用的方法与只写不读的状态字段。
- 删除公众号内置模板主题中未被引用、与 `.css.txt` 源文件内容完全相同的 `.css` 副本，并在代码中注明保留 `.css.txt` 的原因；主题清单 JSON 统一缩进格式。
- ESLint 忽略本地不入库的 `samples/` 与 `coverage/` 目录，避免本地检查扫描逆向样本。

## 文档

- README 新增「Recent releases」版本列表，集中链接各版本说明，正文功能介绍不再夹杂版本补丁说明；简介补充 GitHub 协作、腾讯文档和多平台发布。
- 网络访问说明改为按功能描述：知识大脑入口暂时隐藏，仅在可用并由用户主动开启时访问会员校验与 GitHub。
- 开发说明改为推荐 `npm run check` 一次完成测试、代码规范、类型检查、生产构建和发布资产校验。
- TokenDance 文档注明聊天回复重复问题已在 1.2.1 修复。

## 升级与验证

- 最低支持桌面版 Obsidian 1.11.4。手动更新使用本 Release 的 `main.js`、`manifest.json`、`styles.css`，更新后关闭再开启 WeSight 或重启 Obsidian。
- 发布检查包括完整自动化测试、代码规范检查、TypeScript 检查、生产构建和发布资产校验。
