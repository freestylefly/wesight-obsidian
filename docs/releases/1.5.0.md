# WeSight for Obsidian 1.5.0

发布日期：2026-10-31。

新增腾讯文档连接器，支持浏览器登录授权、带图发布及原文档更新；完善浏览器发布助手安装指引，并暂时隐藏知识大脑入口。

## 腾讯文档

- 「分享」新增「腾讯文档」，位于「飞书」右侧；「设置 → WeSight → 通用 → 连接器」新增腾讯文档卡片，位于飞书下方。
- 点击「登录授权」，在腾讯文档官方页面登录并授权后，插件自动完成连接，无需手动复制凭证。连接器支持检测连接、取消授权等待和断开连接。
- 当前笔记的标题、正文、常用格式的本地图片和网络图片可一同发布。较大的静态图片会自动压缩后上传，读取、转换或上传失败时显示提示。
- 已发布笔记支持「更新腾讯文档」，同步修改后的正文、图片和标题，保持原链接不变。内容没有变化时显示最新状态，也可选择创建新的文档。
- 发布成功后可打开或复制文档链接，笔记保留关联文档及同步状态。复制笔记继承相同文档关联时，会提示创建新的文档，减少误覆盖。
- 授权凭证保存在 Obsidian 安全存储中。断开连接会清除本机保存的凭证，已创建的腾讯文档继续保留。

## 分享与浏览器发布

- 改善本地图片链接识别，兼容文件名中的空格、括号、转义字符和百分号。
- 浏览器发布助手安装入口统一指向 Chrome 应用商店，商店版由浏览器自动更新。
- 连接页和小红书、微博、即刻等工作台同步更新安装及重连提示。曾通过 ZIP 安装的用户，请先处理旧版未完成草稿，再停用旧版扩展、安装商店版并重新连接。

## 知识大脑入口

- 暂时隐藏设置中的知识大脑、Chat 中的「知识库」、相关收录按钮和命令入口。
- 已有知识文件和对话历史保留，打开历史对话时可继续普通 Chat。

## 同期云端更新

以下后台功能已在线上提供：

- 会员管理支持取消会员，并记录操作人和取消原因；取消后会员权益及剩余会员积分立即失效。
- 用户、会员和积分管理支持按登录来源筛选观猹账号，并使用昵称、观猹 ID、WeSight 用户 ID 或已同步手机号查找。
- 账户详情显示用户 ID，便于准确定位账号。历史账号的手机号需要重新登录且观猹返回完整号码后才能同步。

## 升级与使用说明

- 最低支持桌面版 Obsidian 1.11.4。升级后关闭再开启 WeSight，或重启 Obsidian。
- 腾讯文档同篇更新目前支持单页智能文档，更新前会提示云端直接编辑的内容将被覆盖。若中途失败，原链接会保留，请检查文档后重试。
- 腾讯文档连接与发布无需额外安装 CLI。详细步骤见[腾讯文档连接器](../tencent-docs.md)。
- 发布检查包括完整自动化测试、代码规范检查、TypeScript 检查、生产构建和发布资产校验。自动化测试使用模拟接口，未执行真实充值或最终发帖。
