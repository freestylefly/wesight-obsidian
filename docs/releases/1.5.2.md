# WeSight for Obsidian 1.5.2

发布日期：2026-11-05。

「快速转」支持跳过 AI 生成，直接使用当前文案和所选图片进入多平台发布流程。

## 快速转与直接发布

- 底部同时保留「一键生成文案」和「一键发布到 N 个平台」。小红书、微博、即刻和 X 均可使用已有或手动编辑的文案，AI 生成按需使用。
- 发布使用当前选中的图片及排列顺序；调整选图后可直接发布，保留已有文案与图片工作台内容。
- 部分平台生成失败时，可编辑当前文案后继续发布，也可重新生成。发布仍会检查平台选择、图片、文案格式及字数要求。
- X 尚无保存文案时，预填原文纯文本；原文正文为空时使用文章标题。已保存的手动文案会保留。初始长文案保留完整内容，超过 X 的 280 加权字符限制时，需先手动精简正文或话题。
- 保留有效会员、浏览器连接和扩展能力检查。快速转准备发布期间锁定平台、选图和文案编辑，避免重复点击创建多个任务。
- 一键发布会打开浏览器动态发布中心，带入各平台文案与图片；可继续检查、调整并选择同步平台，最终发布由用户确认。

## 升级与验证

- 最低支持桌面版 Obsidian 1.11.4。手动更新使用本 Release 的 `main.js`、`manifest.json`、`styles.css`，更新后关闭再开启 WeSight 或重启 Obsidian。
- 未连接浏览器发布助手时，会打开连接器设置；完成连接后，再次点击发布。
- 回归覆盖跳过生成、部分生成失败、选图排序、X 手动文案恢复、内容超限拦截及重复发布保护；发布检查包括完整自动化测试、代码规范检查、TypeScript 检查、生产构建和发布资产校验。
- 已在实际 Obsidian 仓库中重载验证，未生成内容时两个入口均可用。会员和发布接口测试使用模拟数据，未执行真实平台最终发帖。
