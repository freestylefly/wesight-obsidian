# WeSight for Obsidian 1.4.0

发布日期：2026-10-17。

新增动态发布中心交接与 X 图文转换，集中管理浏览器发布助手连接，并将转为图文、连接和平台交接设为会员功能。

## 图文动态与 X

- 「转为图文」默认进入快速转，可选择小红书、微博、即刻和 X，分别生成文案或使用统一文案；生成后继续编辑正文、话题和图片顺序。
- 一键发布会带入各平台独立文案和图片，打开浏览器发布中心的「动态」页；即刻圈子一同保留，在浏览器选择同步平台。
- 新增 X 独立短文案，按 X 官方加权规则检查 280 字符限制；默认选取前 4 张支持的 PNG、JPEG 或 WebP 图片，单张不超过 5 MB，跳过的图片会提示。
- 图文生成文字建议 600–900 字，正文、话题、空格和换行合计最多 1,000 字；手动编辑超限时提示调整，小红书同步前再次检查。
- 聊天顶栏增加多平台文章入口，文章与动态分别进入对应发布中心。

## 浏览器连接与会员

- 「设置 → WeSight → 通用 → 连接器」新增浏览器发布助手卡片，集中提供安装、连接、检测、重连和断开操作，并显示连接状态与扩展版本。
- 未连接时，发布入口打开连接器设置，保留已有文案、图片和平台选择。连接操作独立完成配对。
- 转为图文、浏览器发布助手连接及平台交接需要有效 WeSight 会员，单平台同样适用。非会员和到期会员会看到「去充值会员」，进入现有会员充值页；未登录时先引导登录。
- 操作前刷新会员状态，已有配对和旧任务链接也会校验；网络错误提示重试。关闭界面后，等待中的会员检查不会继续打开连接页或创建发布任务。

## 仓库同步

- 断网时自动同步静默跳过，恢复网络后按原设置继续。
- 自动同步的明确网络故障不再写入失败列表；手动操作失败、认证问题和合并冲突仍保留提示。

## 升级与验证

- 最低支持桌面版 Obsidian 1.11.4。更新本 Release 的 `main.js`、`manifest.json`、`styles.css` 后，关闭再开启 WeSight 或重启 Obsidian。
- 请同时更新到 [浏览器发布助手 1.1.0](https://github.com/freestylefly/wesight-chrome/releases/tag/v1.1.0)，更新后重新加载扩展，再到 Obsidian 连接器设置重新连接。
- [Chrome 安装包](https://github.com/freestylefly/wesight-chrome/releases/download/v1.1.0/wesight-chrome.zip) · [Edge 安装包](https://github.com/freestylefly/wesight-chrome/releases/download/v1.1.0/wesight-edge.zip)。解压后，在对应浏览器扩展管理页加载完整文件夹。
- 浏览器 1.1.0 包含独立账号登录、文章和动态发布中心、平台登录检测、X 文章与图文动态同步、即刻圈子及新内容重置。X 动态默认只同步标题和正文，话题字段默认不同步，正文中手写的话题保留。各平台最终发布仍由用户点击确认。
- 发布前执行完整测试、代码规范检查、TypeScript 检查、生产构建和发布资产校验。会员与平台写入相关自动化测试使用模拟接口，未执行真实充值或最终发帖。
