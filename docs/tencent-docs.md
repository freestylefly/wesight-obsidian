# 腾讯文档连接器

在 WeSight 设置的「连接器」中，腾讯文档位于飞书下方。

1. 点击腾讯文档连接器中的「登录授权」，插件会打开[腾讯文档官方授权页](https://docs.qq.com/scenario/open-claw.html?nlc=1)。
2. 在浏览器中登录腾讯文档账号，并确认授权。
3. 保持 Obsidian 的连接器设置页打开，插件会自动获取授权结果，检测通过后显示「已连接」，无需手动复制凭证。
4. 打开笔记的「分享」，选择飞书右侧的「腾讯文档」，确认标题后点击「发布到腾讯文档」。

授权链接有效期为 5 分钟。可以重新打开授权页或取消当前流程；离开设置页会停止等待。若链接过期，重新点击「登录授权」即可。需要手动配置时，展开「使用授权凭证连接」填写已有凭证。

首次发布会创建一篇新文档。面板默认勾选「后续更新同一篇腾讯文档」；已发布笔记显示「更新腾讯文档」，确认后会使用当前笔记的正文、图片和标题更新原文档，链接保持不变。内容一致时提示「已经是当前笔记的最新内容」，并禁用更新按钮。需要单独保留一份时，点击「创建新的腾讯文档」或取消勾选同篇更新。

发布成功后可以打开、复制文档链接，文档 ID、链接、发布内容指纹、标题与时间会保存到当前笔记的 `wesight-tencent-*` 属性中。旧版仅保存 ID 和链接的笔记也可更新；复制笔记继承了相同文档 ID 时，面板会引导创建新文档。本地图片和网络图片会通过腾讯文档官方接口上传。本地图片支持 PNG、JPG、JPEG、GIF 和 WEBP；网络图片额外支持 BMP 和 SVG。超过 512 KB 的 PNG、JPG、WEBP、BMP 会自动压缩后上传，以减少传输失败；压缩时透明区域转为白底，GIF 和 SVG 保留原文件。单张原图最大 10 MB。发布过程中出现的内容转换提示会在分享面板中展示。

授权 Token 保存在 Obsidian 的 SecretStorage 中，不写入笔记、插件设置或日志。设置中的「断开」会清除本机保存的 Token；如需撤销腾讯侧授权，请前往官方授权页管理。已经创建的文档会保留。

连接器直接使用腾讯文档官方 MCP 服务 `https://docs.qq.com/openapi/mcp`，无需安装额外 CLI。浏览器授权采用腾讯文档官方 [Skill 包](https://cdn.addon.tencentsuite.com/static/tencent-docs.zip) 中的登录流程：本机生成一次性授权标识，通过官方页面完成登录后轮询官方接口获取结果。一次性标识仅保存在内存中，获取的授权凭证验证后写入安全存储。

创建文档时显式使用 Markdown 模式（`content_format: "markdown"`）；更新时将正文转为腾讯文档支持的 MDX，并使用 `<Image />` 插入上传后的图片。更新目前支持单页智能文档。腾讯当前更新接口对富文本链接地址的处理存在差异，更新后的链接会同时保留完整地址文本，便于复制访问。

更新确认会提示云端直接编辑的内容将被覆盖。腾讯文档通过多个接口完成正文替换；若中途失败，面板会保留原链接并提示远端可能已部分更新，可以检查后重试。
